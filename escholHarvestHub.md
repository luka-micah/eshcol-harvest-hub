# 1. Executive Summary

Eshcol Harvest Hub is an agricultural business based in Jos, Plateau State, Nigeria, initially focused on producing and selling fresh bell peppers.

The goal of this project is to build a modern digital platform that combines:

1. A professional farm website.
2. An online shop for household customers.
3. A bulk-order and quotation channel for retailers and offtakers.
4. Farm pickup and delivery fulfilment.
5. Customer and order management.
6. Inventory management.
7. Farm production and harvest tracking foundations.
8. Farm storytelling and content marketing.
9. An administration dashboard.

The platform must be designed so that Eshcol Harvest Hub can begin with bell peppers and later add other farm produce without a major architectural rewrite.

The long-term positioning is:

> **Eshcol Harvest Hub — Growing Fresh. Connecting Markets. Feeding Communities.**

Primary consumer-facing message:

> **Fresh From Our Farm. Grown With Care.**

# 30. Payment Integration

Use **Paystack**.

Payment flow:

```text
Checkout
   ↓
Create pending order
   ↓
Initialize Paystack transaction
   ↓
Customer pays
   ↓
Paystack callback/webhook
   ↓
Verify transaction server-side
   ↓
Mark payment PAID
   ↓
Confirm order
   ↓
Reduce/reserve inventory
   ↓
Send confirmation
```

Security rules:

- Never expose secret key in frontend.
- Verify transactions server-side.
- Verify webhook signatures.
- Use idempotency where appropriate.
- Never mark an order paid solely because a frontend callback says payment succeeded.

# 35. Architecture Principles

Follow these principles:

1. TypeScript everywhere.
2. Strong typing.
3. Server-side validation.
4. Client-side validation for UX.
5. Never trust client-side prices.
6. Never trust client-side inventory.
7. Keep payment secrets server-side.
8. Use environment variables.
9. Never hard-code API URLs.
10. Use reusable components.
11. Separate UI from business logic.
12. Use service/repository patterns where appropriate.
13. Use database transactions for order/payment/inventory operations.
14. Design for mobile first.
15. Build accessibility into the UI.
16. Optimize images.
17. Build SEO into the architecture.
18. Use clear error handling.
19. Log important server-side events.
20. Keep MVP scope controlled.
